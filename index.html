把选定的录音转为可查阅文本

这是供所有者个人使用的转录工作流。它读取本人授权的 Google Drive 音频或视频，调用 AssemblyAI 生成转录，再把成果保存到原文件夹。

本工具不提供公众注册或面向公众的转录服务。此页面仅介绍应用，不提供媒体上传或账号登录入口。

如何处理一次任务

  1. 所有者明确选择 Google Drive 中的文件，通过私有 GitHub 仓库发起任务。
  2. GitHub Actions 使用 Google Drive OAuth 授权，先检查目标文件夹的读取和写入能力，再读取选定媒体。
  3. 选定媒体上传到 AssemblyAI 进行语音转录；工作流获取识别结果。
  4. TXT、SRT、JSON 成果及用于恢复和去重的任务标记保存到源媒体所在的 Drive 文件夹。归档后会读回核对。

输出与恢复

TXT 和 SRT 包含时间信息；模型返回说话人标签时，输出会保留标签。JSON 保存用于核对的识别结果。已有成果和已记录的任务编号用于跳过重复转录或恢复任务。

工作流还将成果及可恢复任务记录保存为私有 GitHub Actions Artifact，当前配置的保留期限为 30 天。原 Drive 文件夹中的成果由所有者管理。

使用前应了解

媒体会由 Google Drive、GitHub Actions 和 AssemblyAI 参与处理。自动识别可能出错，说话人标签也不等于对真实身份的确认。请先阅读隐私说明和个人使用条件。
