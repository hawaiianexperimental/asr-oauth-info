隐私说明

本说明对应所有者个人使用的 Google Drive → GitHub Actions → AssemblyAI 直连转录流程。它说明实际处理的数据和存放位置，不承诺数据不经过第三方或始终不会发生安全风险。

读取与生成的数据

  • 指定 Drive 文件夹及选定媒体的名称、文件标识、类型、大小等元数据，以及需要转录的音频或视频内容。
  • AssemblyAI 返回的转录文字、时间信息、说话人标签及其他识别结果字段。
  • 用于任务执行、去重和恢复的任务编号、状态、源文件关联信息及成果链接。

Google Drive 授权的用途

当前应用请求 Google Drive 读写权限。运行时使用这些权限读取指定文件夹和明确选定的媒体，并创建或更新 TXT、SRT、JSON 成果及任务标记。

预检会在目标文件夹创建临时测试文件、读回内容并清理该测试文件。当前转录流程不会因完成转录而删除原始媒体；已有成果及任务记录用于防止重复提交。

OAuth 凭据保存在私有仓库的 GitHub Actions Secrets 中，供任务访问 Drive。重新授权由本机脚本取得授权并写入 Secrets；这些凭据不应被放入说明页面、Issue、源码或转录成果。

哪些服务参与处理

Google Drive 保存源媒体和归档成果。私有 GitHub Actions 运行任务、读取媒体并将选定媒体发送到 AssemblyAI。AssemblyAI 执行语音识别并返回结果。因此，媒体内容及相应识别结果会经过这些第三方服务。

GitHub Issue 和执行日志可包含文件名称、任务状态、任务编号及成果链接等运行信息。相关数据受对应账号、仓库和各服务自身的权限配置与服务政策约束。

保存时间与管理

  • Drive 中的原媒体、转录成果和任务标记由所有者管理；工作流没有为这些文件设置自动删除期限。
  • 私有 GitHub Actions Artifact 中的成果及恢复记录，当前配置保留 30 天。Issue、日志等记录应通过 GitHub 各自的管理与保留设置处理，不能据此推定也统一保留 30 天。
  • AssemblyAI 的数据保留及删除行为取决于其现行政策和实际账号配置；本页不设定或承诺一个尚未核实的期限。

停止授权与后续处理

所有者可在 Google 账号的第三方连接设置中撤销本应用授权，并停用相关工作流或移除仓库中的 OAuth Secrets。撤销授权会影响后续 Drive 访问，但不等于自动删除已经生成或传送的数据；已有数据需在各对应平台分别管理。

本应用仅供所有者个人使用，不提供公众账号。
